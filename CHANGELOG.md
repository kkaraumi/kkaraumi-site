# Changelog

Все заметные изменения проекта записываются в этот файл.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.1] - 2026-11-01

### Added

- Котик на нитке сбоку страницы: спускается при прокрутке и раскачивается.
- Анимация котика, играющего с клубком, на главном экране.
- Мяуканье и мурчание котиков-стикеров через Web Audio API.

### Changed

- Котики-стикеры теперь отвечают репликами вместо перетаскивания.
- Обновлены тексты в разделах «Стек» и «Хобби».

### Fixed

- Ссылка «Код на GitHub» у проекта «Этот сайт» вела на несуществующий репозиторий.

## [1.0.0] - 2026-10-28

### Added

- Главный экран: имя, короткое описание, факты (откуда родом, где учусь, на чём пишу), фото в арке.
- Окно редактора с файлом `evgenia.py`, код появляется построчно.
- Разделы «Обо мне», «Стек», «Проекты», «Хобби» и «Контакты».
- Уровень навыков в лапках.
- Превью проектов: поле «Морского боя» и мини-браузер с сайтом.
- Плитки хобби: снежинки у Dota 2, эквалайзер у вокала, тетрадная линейка у писательства.
- Фишка: контакты охраняет котик, после нажатия на лапку он взрывается розовым ядерным грибом и контакты открываются.
- Счётчик взрывов и звук взрыва через Web Audio API (по умолчанию выключен).
- Котики-стикеры, которых можно перетаскивать и тыкать.
- Меню с подсветкой текущего раздела, бургер на телефоне.
- Отдельная вёрстка для телефона, поддержка `prefers-reduced-motion`.
- Мета-теги для превью ссылки, favicon.
- Автоматическая выкладка на хостинг через GitHub Actions.
